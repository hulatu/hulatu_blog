你来到了这个站的地图室。这一页有两个用途：找入口，以及看这个站是怎么搭起来的。

## 读什么

[文章](/archive/) 按年份分组，从新到旧；想从头翻，可以从最后一页开始。[分类](/categories/) 按主题把文章分成几组，适合想连着读同一类内容的时候。[周刊](/weekly/) 每周日更新，是这一周读到、用到、想到的东西。[系列](/series/) 把连载收在一起，适合一次读完一个主题。

如果只想随便看看，首页的「最近更新」就是最近的五篇。

## 逛什么

[跑步](/run/) 是从 Garmin 同步过来的里程、配速和心率，按年折叠。[工具](/tools/) 是我写过的几个小工具：文章分发台、少数派阅读增强等。[邻居](/roll/) 是我常读的博客、认识的朋友，以及常逛的中文博客圈和聚合站；想交换友链，那页也写了我的信息。

如果这个站对你有帮助，可以在 [支持](/donate/) 里请我喝杯咖啡。

## 关于这里

[关于](/about/) 是我这个人，也是联系方式所在。[样式](/style/) 是所有 Markdown 元素的渲染样本，改版时用来对照。[隐私](/privacy/) 说明这里会处理哪些数据。

## 这个站

### 技术栈

站点用 [Hugo](https://gohugo.io/) 生成，主题是 [Bear Neo](https://github.com/rokcso/hugo-bearneo)，在这个主题上做了一层站点级覆盖。主题文件本身只有六处登记过的改动：正文行高、列宽、代码块圆角、已访问链接颜色、删掉未启用的 upvote 样式、深色改用 `data-theme`；其余样式都写在站点自己的 CSS 里，方便下次同步上游。

源文件放在 GitHub，构建和托管在 Cloudflare Pages，图片放在 Cloudflare R2。评论用 Giscus（GitHub Discussions），访问统计用 GoatCounter，并且走了同源代理，浏览器不会直接连到第三方统计域名。

没有 CDN 字体、没有前端框架、没有广告。页面用系统字体渲染，所以首屏不依赖任何外部资源。

### 排版

正文最大宽度 680px，字号 17px，行高 1.8（行盒 30.6px），段间距 32px。标题固定为 H1 38 / H2 32 / H3 24 / H4 20 / H5 18 / H6 16，不随基准字号漂移。

全站只有一个强调色：链接蓝 `#1D4ED8`（深色模式 `#60A5FA`）。亮色底 `#FCFCFA`，深色底 `#111214`。右上角 `☾/☀` 可手动切换深浅色。引用框用同一支蓝色画竖线，配一层很浅的底色和一个低饱和的大引号。

所有 Markdown 元素的完整样子，都放在 [样式](/style/) 这一页，改排版前先去那里对照。

### 评论与隐私

评论区基于 Giscus，需要 GitHub 账号；如果不想公开评论，或者评论区加载不出来，欢迎到 [关于](/about/) 找我。两种方式我都会看。

这个站不收集账号、不埋第三方追踪脚本，也不用 Cookie 做画像。GoatCounter 只记录页面浏览量，用来知道哪些文章有人读。具体的隐私说明在 [隐私](/privacy/)。
