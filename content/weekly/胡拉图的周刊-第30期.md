## 少「刷」点抖音

没错，我真的很不喜欢看到身边有人「刷」抖音、讨论抖音热点。

有些人的能力都退化成啥样了！和人打招呼不喊称呼、给到你很多东西的答案了，你连搜索都懒得搜索一下，并且反过来质疑我「为什么不给你下好」？我的天，你清楚自己这是个什么行为嘛？

![没礼貌的对话](https://img.hulatu.com/post/rz0CWd.png)

抖音真的是当代社会的一个「变相稳定器」，只要你在移动端 APP 一打开它，你基本上就丧失了思考的时间和空间。因为它打开就是自动播放的、并且以指尖滑动的操作让人可以随时更换内容。让你完全没有了「主动搜索」的概念。

有的人说我可以在抖音视频上学到很多知识、生活常识。其实这也是个误区。很多和你息息相关、你想要了解的东西，你其实会去「搜索」。比如你不知道乘坐飞机有什么注意事项无论是使用 AI、搜索引擎、小红书等工具，你都能更快、更直接、更有针对性的解决你生活中遇到的问题。而不是去「被动」的刷视频，让它给你推一些你其实压根就用不上，但你觉得有用的东西。

没有了主动搜索的意识，一个人「自己动手」解决问题的能力，就会大大下降。他容易把生活都当成「推送模式」——只要我有需要，联系懂这个东西的人，他就会毫无保留的告诉我答案、喂到我口中。甚至于，他们的表达能力，已经不像是个成年人该有的水平，因为很久没有主动搜索过东西，自然也就很久没有准确、清晰、有逻辑的表达自己心理的真实想法和需求，表达能力怎么能得到提升呢？反而获得了瞎眼可见的退化。

我不否认抖音里有好的内容，并且它应该是简中世界里拥有极高内容丰富度、创作者数量最多的平台了，有些在其他平台找不到的东西，这个平台上可能有。

为了好好利用它，我希望大家可以学会在网页上「用」抖音，这样会让你「动手搜索」的欲望强烈一些，并且看内容的过程中，做笔记的阻力，会小一些。这样，或许会更有益于你学到一些什么。

## 不值得清单

听了 Naval（纳瓦尔）的一个访谈，我们普通人，其实可以给自己搞一个《不值得清单》：

1. 不值得关注的领域（与核心目标无关的新闻和信息）；
2. 不值得争论的话题（无法验证真假、无法改变结果的争论）；
3. 不值得了解的热点（一周后没人记得了）；
4. 不值得交往的人（消耗你情绪能量的人）。

我觉得这个世代，身边越来越少见到能够「专注、长时间」做一件事情的人了，我自己也是如此。所以我觉得大家有必要理清一下自己到底关注、看重哪一些东西。如果看不清，那就试试去挖掘一下自己目前花费时间太多的领域，有哪些与自己的理想未来和目标并不符合，耽误了自己太多时间、让自己很难集中注意力、有了坏习惯。

我觉得很值得做一做。

比如我自己，很喜欢 NBA，很喜欢库里，所以之前总是很喜欢蹲厕所的时候打开关于篮球的论坛，看勇士、看库里的一些帖子，但是遇到不客观、没逻辑的言论，哪怕我不去评论，也会影响我的心情；还有的人，会仗着「我好想和你很熟」，说话和做事没有分寸、甚至于从来不把我「只对你」聊过的东西当作隐私去对待、而是随意的告诉别人，那么我会对你冷漠、远离。

成年人的世界就是筛选，甚至于你的家庭给你带去的永远是压力和不快乐，你也应该适当的与他们疏远、并且早日学会独立。

## WorkBuddy 剪视频

如果我今天就被宣布研究生毕业了！我第一件想投入精力做的事情，就是拍摄视频！我有几个擅长的领域、或者说知识储备相对比较丰富——跑步、力量训练和饮食；写内容、记录分享自己；吃播、食物评测以及知识科普；最后再加上一个直播互动。

我其实对自己挺有信心的，我也相信我能做出一番小成就。

上周我把我的一篇文章内容，拍成了视频，粗剪过后，我觉得配字幕、做封面、取标题……这些工作都太繁琐，于是乎我去找方法、找经验分享，如何利用目前正火的 AI Agent 帮助自己剪辑视频、完成一些视频相关的工作。

于是乎我了解到：用 AI Agent 配置好一些开源工具，AI Agent 就可以自动给我们剪视频了，并且能够生成字幕、烧录字幕、设计封面等等。

最后我把它做成了一个 skill，以后只需要把 WorkBuddy 定位到我的视频文件夹，给一个指令，它就能给我剪视频。

| 工具        | 功能                                                 |
| ----------- | ---------------------------------------------------- |
| yt-dlp      | 网络素材与字幕下载                                   |
| ffmpeg      | 剪辑引擎：切割、拼接、转场、调色、变速、画中画、压缩 |
| LosslessCut | 可视化无损粗剪（图形界面）                           |
| auto-editor | 自动去除视频静音部分                                 |
| mlx-whisper | 字幕生成，Apple GPU 加速，中文识别实测 100% 准确     |
| vsub        | vsub 视频.mp4 --burn 一条命令出字幕+硬字幕成片       |

这个表格里是一些开源的与视频制作相关的工具，把它们下载好，AI Agent 就能自动给我们完成视频任务，效果还不错。可能因为我的普通话不太标准，所以最终在字幕文件上，需要做一些调整。但已经显著提升了我的效率。

## 尝试创作工具

上周，我发布了一篇文章：[分享 3 个小工具](https://hulatu.com/posts/2026/11/08/three-small-tools/)，里面提到了我最近做的 3 个小工具，我觉得对我个人的帮助，还是挺明显的。大家可以去我的 [GitHub](https://github.com/hulatu) 看看我的项目——一个文章发布台、一个网页全屏脚本、一个少数派增强脚本，或许对你有用。

关于制作工具，我个人有一些感想，想要分享一下：

首先：工具和 AI 的区别，我觉得我们应该有所了解。AI Agent 虽然可以帮助我们完成目前工作、学习中的大部分事情，但是它有个劣势——等待时间太长。

如果我们把需要高频用到的功能，通过 AI 抽离成一个工具——专门完成一项任务，那么这个工具处理任务的速度，可比每次提交给 AI 处理快多了。比如一个 word 转 md 文件的网页工具，一定比用 AI Agent 转换，要来的快速高效。这是推荐大家去做一些工具的原因。

其次：不要有完美主义。其实过去我一直不明白，有些应用用的好好的，为什么要版本更新。我自己做了工具后才知道——产品在不断使用过程中，需求的不足和漏洞就会显现。所以版本的更新，就是丰富功能、修复漏洞的过程。再优秀的开发者，它也不可能在一个工具版本中，就做到没有任何的 bug、并且完美的拥有所有功能。所以我们做工具，哪怕是小白，也不要有太大的压力，先把自己对于这个工具的「雏形」做出来——能够满足自己理想要求的 80%，我觉得就很棒了，然后再去挖掘缺失的那一部分，去调整、去优化。

最后：学会清晰表达请求。当我们发现了我们制作的工具有功能缺失、有漏洞，要学会用清晰、有逻辑、需求明确的表达自己的指令，让 AI 懂得我们的需求。这时候，我推荐大家先不要直接在 AI 对话框里给 AI 指令，因为我们很多时候其实没有想清楚、描述明白自己的要求。我们可以现在「文本」软件里，把自己对这个软件的所有想法都写出来，然后可以让 AI 先把我们的想法整理成一个有逻辑的「指令」，然后还可以让 AI 问我们问题——怎样可以让我的工具更完善、使用体验更好？然后在指令上做补充，我觉得这样才是一个好的思路。

## 分享几个工具

### Mac 端右键新建文本

地址：[给 macOS Finder 补上右键「新建文件」功能 — 免费 Automator 工具](https://sspai.com/post/112095)

一个很干净的 Mac 原生小工具，能直接右键新建「文本」，对于有这个需求的人来说，算是一个功能补充，又避免了各种「右键增强软件」的冗余。

### 追踪零食摄入的 APP

出处：[我做了一个能「抓你吃零食」的 App](https://sspai.com/post/106791)

这是个什么天才哈哈哈，居然能奇思妙想到如此地步——通过 iPhone 的状态检测或者 Apple Watch 的感应，推测我们是不是在某些时间段在吃零食，给我们提醒？让我们自我审视。

我觉得这是个很有想法的设计。我也审视了一下我自己，比如我就很容易在下午忙完、傍晚吃完晚饭的时候吃点零食，因为总觉得这段时间有点「空空」的，有点零食陪伴，会有趣许多哈哈，要是有这个 APP 助力，我肯定还能健康不少。

### 久坐提醒工具

出处：[macOS 菜单栏里的久坐提醒，轻量但够「狠」](https://sspai.com/post/106965)

因为我每天长时间使用的电子工具是 Mac，所以无形中久坐的时间会增加。虽然我的手表 Garmin 255 也有久坐提醒，但总感觉不够直观，很多时候容易被无视。

我逛少数派的时候，发现了这么一个工具，就是这一款 HealthTick，我觉得很轻量、也很够用，到了时间就「强制提醒」自己要站起来休息一下，我认为很有必要。因为现代文明里，我们的昼夜分界线已经不明显、甚至于久坐太长时间身体都难以判定我们是在睡眠还是工作，所以我们需要一些「站起来、动起来」的时刻，告诉身体——我还清醒着，我在工作，不要让我进入节能模式。
