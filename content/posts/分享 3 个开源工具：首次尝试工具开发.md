最近做了 3 个好用的工具，分享给大家：

我喜欢写 [博客](https://hulatu.com/) ，但是常常一篇稿子写完，事情才刚开始。

因为我在不同平台都会发布内容。所以这一篇稿子它得先变成多种形态才能被看见：公众号要全内联样式的 HTML，豆瓣要富文本，少数派要规整的 Markdown，小红书要图文模式……

内容发出去之后，读者在不同平台点进来阅读，又有一个挑战。

读者会发现有些显示页面屏幕有一半是广告和「关联阅读」，还有一些其他的干扰。比如少数派的首页，干扰太多了。

有时候你想打开 YouTube、B 站放松一下，发现「网页全屏」那个按钮藏在控制条里 —— 得先把鼠标移进播放器、等控制条浮出来、再找那个小图标，很不方便。

这三件事看起来毫无关系，但确确实实会影响我们很多使用体验。做这 3 个脚本的过程中，我发现，我干的是同一件事：**把平台的默认形态转变成更适合我个人的使用习惯**。

于是有了我自己编写了三个工具。都不大、不复杂，但能解决一些痛点、提升一些体验，这些工具都开源，供大家使用。

## 文章分发台：一稿多态

地址：[文章发布页](https://github.com/hulatu/Publishing_Platform)

同一篇文章、同一个 `.md` 文件，导入 or 粘贴进我的工具页面里，左下方选择平台，右边就可以获得满足不同平台的格式内容。

![文章分发台主界面：左侧是 11 个平台的列表，中间是公众号预览，顶栏实时显示正文字数与字符占用](https://img.hulatu.com/post/Nx2xGf.webp)

做自媒体内容，尤其是写东西的，麻烦的地方在于，我写了一篇文章，每个平台要求的格式、主流内容展示方式，根本不是一个东西：

| 平台                           | 怎么处理                                                     |
| :----------------------------- | :----------------------------------------------------------- |
| 少数派、知乎                   | **直接转**：规整的 Markdown + 图片上传清单                   |
| 微信公众号                     | **要排版**：全内联样式的 HTML（微信不认 `<style>` 和 `class`） |
| 豆瓣、B 站专栏、头条号、百家号 | **要清洗**：标准 HTML，清洗强度依次递增                      |
| 小红书、推特、即刻、微博       | **要改写**：按平台语气重写的短文案 + 配图                    |

**几个小亮点**

- **发布台账**：复制即标记已发，多个平台的进度一眼看到，链接可以事后补
- **草稿箱**：摘要、四平台文案、标题候选自动存盘，关掉标签页也不丢
- **合规检查**：本地词表 + 正则，不联网，正文一个字节都不出浏览器
- **配图卡片**：封面 + 每个小节一张 + 结尾，3:4 / 1:1 / 16:9 三种比例按比例重排（不是整体缩放，不然 16:9 的字会小一半）
- **标题与标签**：一次给 8 个角度，至少 3 条在 20 字内 —— 小红书标题上限就在那

**不做一键发布**

公众号没有给个人开放发布接口，绕过去的路子都是灰色地带。所以这个工具只做两件事：**把产物复制到剪贴板**，和**复制完把发布页打开**。

不碰账号、不填表、不代发。多按一次「粘贴」，换的是不用把登录态交给一个网页工具 —— 这笔交易我觉得值。

它也没有服务器。Key 存在你自己浏览器的 `localStorage` 里，请求从浏览器直连服务商，没有任何中转。所以它断网也能打开（Service Worker 缓存了外壳），草稿箱照样能看。

## 少数派阅读增强：一切为了阅读

地址：[少数派增强脚本](https://github.com/hulatu/sspai-tidy)

我经常看少数派的内容，但少数派的首页和文章列表做的并不好。它的首页文章列表页把三分之二的屏幕给了轮播、侧栏和推广卡；文章页在正文之后又堆了广告、打赏、评论和「关联阅读」，我觉得用着不舒服。

我的这个脚本做的事很简单：把它们拿掉。

![改造后的少数派首页：列表拉宽到 1064px，单条压到 99px 高，一屏能看 9 篇](https://img.hulatu.com/post/flV5bI.webp)

使用脚本后，一屏从 4 篇变成 9 篇，这个差别不只是「好看一点」，而是我「更愿意打开、浏览更舒服」。

文章页更夸张。一篇长文原文大部分显示的并不是正文：

| 清掉的块                    | 高度      | 是什么                              |
| :-------------------------- | :-------- | :---------------------------------- |
| `.related__read__wrapper`   | 864px     | 关联阅读板块                        |
| `.advertisement__box`       | **398px** | 文末广告位                          |
| `.comment__footer__wrapper` | 392px     | 正文末尾的「发表首评 + 表情」互动条 |
| `.post__comments`           | 237px     | 底部固定栏的评论区入口没丢          |
| `.article__charge__card`    | 222px     | 派友充电、打赏显示                  |

用我的脚本清理、处理后，保留的是正文、文章标签与责编信息、目录，以及底部那条「说点什么…／分享」固定栏，都是有用、能用上的部分。

![改造后的文章页：正文之后直接结束，没有广告、打赏和「关联阅读」](https://img.hulatu.com/post/V7NOrX.webp)

深色主题下同样生效，颜色全部走站点自己的 CSS 变量：

![深色主题下的列表页：颜色全部走站点自己的 CSS 变量，脚本不另配一套](https://img.hulatu.com/post/Vy6GrJ.webp)

并且我的这个脚本，可以实现你进入「某个创作者主页」，默认的显示从「动态」变成「文章」，我觉得才更符合大部分人的需求——我对你的某篇内容感兴趣，以至于对你这个人感兴趣，想看你更多的原创内容、而不是你的动态。

希望你们喜欢。

## 网页全屏：一键直达

地址：[网页全屏工具](https://github.com/hulatu/Video-Fullscreen)

我喜欢用电脑浏览器看 YouTube 和 bilibili 的内容，但有时候也需要在浏览器里处理别的事情，所以我想要「视频」的显示范围尽可能大、而且没有别的东西干扰。网页全屏是个很好的功能，但是并不是每个网站都适配，而且就算适配了，用起来也没那么「方便」。对于我来说，网页全屏是个高频使用的功能，所以理应像我平时使用 Mac 的快捷键那样方便。

「网页全屏」这个按钮，在大多数视频站上都藏在播放器右下角的控制条里。有些站干脆没有这个按钮，只有「全屏」—— 那个会真的接管整个屏幕，切换窗口就得退出。

我这个脚本，把「网页全屏」变成一个 `Esc` 键。

| 按键  | 做什么          | 什么时候不接管                                       |
| :---- | :-------------- | :--------------------------------------------------- |
| `Esc` | 网页全屏 / 退出 | 光标在输入框里、已经在系统全屏、页面上没有像样的视频 |
| `F2`  | 画中画 / 退出   | 光标在输入框里、页面上没有像样的视频                 |

![CSS 兜底全屏：视频铺满视口，页面其余部分让开](https://img.hulatu.com/post/bD19ut.webp)

![按钮条：磨砂玻璃的两个按钮，鼠标停手 2.5 秒自动收起](https://img.hulatu.com/post/4BgcH6.webp)

我觉得，对于很多喜欢在浏览器上看视频网站的人，这个脚本有很大帮助，会持续提升使用体验。

## 三个工具的共同点

这三个东西虽然感觉不同类别、不同风格，但其实做法和目标却很明确、很专一：

**只做一件事** ：分发台不做发布，少数派脚本不改内容，全屏脚本不管 iframe 里的播放器。边界划清楚。

**不收集数据**： 三个工具都没有服务端，Key 在 `localStorage`，已读记录在 `localStorage`，视频脚本一个请求都不发送。

**全部都开源**： 改坏了别找我，改好了欢迎提交分享。

## 安装、使用方法

这三个工具，两个是 Tampermonkey 脚本，一个是网页应用：

1. **文章分发台**：打开 [publish.hulatu.com](https://publish.hulatu.com)，把自己的 `.md` 添加或者粘贴进去。不用注册，不用登录，AI 功能可选（自己填 Key），生图和内容总结。
2. **少数派阅读增强**：装 [Tampermonkey](https://www.tampermonkey.net/)，点 [sspai-tidy.user.js](https://raw.githubusercontent.com/hulatu/sspai-tidy/main/sspai-tidy.user.js) 。
3. **网页全屏**：点 [Video-Fullscreen.user.js](https://raw.githubusercontent.com/hulatu/Video-Fullscreen/main/Video-Fullscreen.user.js)，打开一个视频按 `Esc` 。

两个脚本以后我推新版本，Tampermonkey 会自己提示更新，不用手动重装。

---

写这三个东西最大的收获，倒不只是满足了自己的成就感 —— 而是让自己每天实实在在会用到东西，变得更好用了、体验更舒适了。

大部分时候「少一步、清爽一些」，对于工作效率和使用体验上的提升，是很直观的。

工具的意义大概就是这个：把「少一步」从愿望变成现实、变成专属于自己的默认模式。工具，就得是为自己的个性化需求服务。
